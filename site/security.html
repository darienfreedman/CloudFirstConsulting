Secure access and virtual private networks

Connect people to apps.
Not your entire network.

Move eligible user-to-application access away from broad legacy virtual private network (VPN) connectivity toward identity-aware, per-application access. Entra Private Access provides Zero Trust Network Access (ZTNA); Entra Internet Access provides an identity-aware secure web gateway (SWG) for internet and software as a service traffic.

Together these Global Secure Access capabilities form part of security service edge (SSE). SSE supplies the cloud security component of a broader secure access service edge (SASE) architecture; Entra is not a replacement for every networking or software-defined wide area networking capability.

Entra SuiteEntra Private AccessEntra Internet AccessConditional Access

What we address

  • Discover VPN use, application dependencies, protocols, and user access requirements.
  • Design ZTNA policies, private network connectors, and app-specific access with Entra Private Access.
  • Plan SWG traffic forwarding, web filtering, and identity-aware policies with Entra Internet Access.
  • Integrate identity risk, device posture, and Conditional Access with monitoring and support procedures.
  • Pilot supported scenarios, test compatibility and recovery, then retire redundant VPN access in stages.

A practical output

An application-access inventory, secure-access design, phased VPN modernization plan, policy baseline, and operational handover.

Measures to agree: applications moved to per-app access, reduced broad network access, connection reliability, policy exceptions, and support demand. Confirm client, protocol, region, and licensing support; retain required site-to-site or unsupported VPN scenarios until a suitable alternative is proven.
